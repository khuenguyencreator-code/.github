## 📌 Danh Mục Mã Nguồn Theo Hệ Thống

Để tiện cho việc tìm kiếm, bạn có thể truy cập nhanh vào mã nguồn của từng dòng chip và hệ điều hành dưới đây:

### 🔹 Vi Điều Khiển & Vi Xử Lý (MCU)
* 🛠️ **STM32 (HAL & RTOS):**
  * [STM32F103 HAL Examples](https://github.com/khuenguyencreator/stm32f103-hal-examples) — Code mẫu HAL cơ bản cho người mới bắt đầu (CubeMX + Keil C).
  * [STM32 Device Drivers](https://github.com/khuenguyencreator/stm32-device-drivers) — Thư viện giao tiếp linh kiện, cảm biến.
  * [STM32F103 Device Examples](https://github.com/khuenguyencreator/stm32f103-device-examples) — Các bài tập thực hành thiết bị thực tế.
  * [STM32F103 RTOS Examples](https://github.com/khuenguyencreator/stm32f103-rtos-examples) — Code mẫu FreeRTOS: task, queue, semaphore, mutex…
  * [STM32F407 Examples](https://github.com/khuenguyencreator/stm32f407-examples) — Ngoại vi nâng cao: DAC, SDIO, USB Host/Device, I2S.
* 📶 **ESP32 & IoT:**
  * [ESP32 Arduino Examples](https://github.com/khuenguyencreator/esp32-arduino-examples) — Từ GPIO, ADC, PWM đến WiFi, BLE, IoT và dự án hoàn chỉnh.
* 💾 **8051 Legacy:**
  * [8051 N76E885 Examples](https://github.com/khuenguyencreator/8051-n76e885-examples) — Code ví dụ cho dòng chip Nuvoton 8051.
  * [8051 AT89S52 Examples](https://github.com/khuenguyencreator/8051-at89s52-examples) — Code ví dụ cho vi điều khiển AT89S52 *(sắp cập nhật)*.
